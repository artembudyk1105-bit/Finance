# Финансы для iPhone

Нативное приложение (SwiftUI) для учёта трат и поступлений в стиле iOS 18. Данные хранятся только на телефоне.

## Возможности
- **Голосовой ввод удержанием кнопки 🎙.** Сверху раскрывается «остров» с анимацией записи, волной по громкости голоса и словами, которые вы говорите. Распознавание идёт на устройстве, без интернета.
- **Настоящий Dynamic Island.** Когда трата добавлена через Siri, «Команды» или кнопку действия, результат («Кофе −250 ₽») показывается в Dynamic Island через Live Activity.
- **Кнопка действия и Siri.** Есть три команды: «Голосовая трата», «Записать трату» и «Сколько осталось».
- **Разбор фраз:** «кофе 250 и такси 400», «зарплата 85 тысяч», «вчера аптека пятьсот», «продал велосипед 12к».
- **Обязательные и необязательные траты** определяются автоматически. Для каждой категории можно поменять обязательность и задать лимит.
- **Ассистент:**
  - предупреждает на 70%, 90% и 100% лимита, а также о превышении по прогнозу;
  - считает дневную норму и подсказывает, что убрать;
  - следит за подписками и «эффектом латте» (мелкие покупки, которые складываются в большую сумму);
  - проверяет правило 50/30/20 (половина дохода на обязательное, 30% на желания, 20% в накопления) и считает сроки целей.

  Работает офлайн. С ключом Claude API отвечает на любые вопросы.
- **Статистика (Swift Charts):**
  - кольца как в Apple Watch;
  - график трат с прогнозом и линией лимита;
  - кольцевая диаграмма категорий и календарь трат;
  - годовые столбцы и остаток по месяцам.
- **Архив месяцев.** В начале каждого месяца ассистент сам подводит итоги прошлого.
- **Регулярные платежи** проводятся автоматически. Есть цели накоплений и быстрая смена валюты на главном экране.
- **Сметы:** Excel (3 листа), PDF, CSV. Резервная копия и восстановление из неё.

## Установка без Mac (бесплатно)

Сборку делает GitHub Actions на облачном Mac при каждом изменении в `main`. Готовый файл `Finance.ipa` появляется в **Releases → latest**.

1. Скачайте `Finance.ipa` из раздела **Releases** этого репозитория.
2. Установите на компьютер **Sideloadly** (sideloadly.io, есть для Windows и Mac) или **AltStore** (altstore.io).
3. Подключите iPhone кабелем и нажмите «Доверять этому компьютеру».
4. В Sideloadly перетащите `Finance.ipa`, введите свой Apple ID и нажмите **Start**.
5. На iPhone откройте **Настройки → Основные → VPN и управление устройством**, выберите свой Apple ID и нажмите «Доверять».
6. На iOS 16 и новее включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**, затем перезагрузите iPhone.

С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней. AltStore делает это сам по Wi‑Fi, если компьютер включён. Данные при переподписи сохраняются.

## Кнопка действия
- **С открытием приложения.** Настройки → Кнопка действия → Команда → «Финансы» → «Голосовая трата». Приложение откроется и сразу начнёт слушать, а после паузы остановится само.
- **Без открытия приложения.** Сделайте команду «Диктовать текст» → «Записать трату» и назначьте её на кнопку. Результат покажется в Dynamic Island.

## Разработка
Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen). На Mac выполните `brew install xcodegen && xcodegen generate` и откройте `Finance.xcodeproj`.
